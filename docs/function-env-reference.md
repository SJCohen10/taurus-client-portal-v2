# Function Environment Variable Reference

This document lists environment variables read by each Catalyst function in `functions/*/index.js` plus any local `lib/*.js` it imports. It is intended as an implementation reference for deployment/configuration.

> Notes
> - Variables with fallback defaults are still listed because behavior changes when they are set.
> - Some functions include Catalyst/runtime-provided variables (for example APM/telemetry variables).
